## Conntrack controls

### Summary and affected components

The user requested configurable conntrack limits/timeouts after reviewing TCP
return-packet drops. Added advanced controls without changing the host's current
values or assuming tuning fixes those drops.

- [Core catalog/validation](../../crates/netcontrol-core/src/model.rs):
  nine supported sysctls, exact scopes, integer-string bounds and safety warnings.
- [Simulator](../../crates/netcontrol-core/src/simulator.rs): explicit synthetic
  conntrack baselines for original-value restoration.
- [Native validation](../../crates/netcontrol-native/src/tunables.rs): use core
  catalog bounds for conntrack, retaining native procfs preflight/exact readback.
- [Core model tests](../../crates/netcontrol-core/src/model_tests.rs),

### Decisions and contract impact

Reuse existing `kernel.host`/`kernel.namespace` maps, catalog, HTTP confirmed
transactions, SSH commands, permissions and native ownership/recovery. No new
write endpoint, broad sysctl access, auto-tuning or configuration defaults.

`nf_conntrack_max` is host-global, not namespace-isolated; configure it only
under host ownership (1024..16777216 entries). TCP established/close/close-wait/
fin-wait/last-ack/time-wait and UDP unreplied/stream timeouts are namespace-scoped
(1..604800 seconds). Values remain canonical strings. Numeric bounds are not
hardware memory-sizing advice; low timeouts require explicit operator review.
Read-only count, hash buckets and TCP validation-relaxation settings remain
unsupported. Native preflight also rejects out-of-range captured originals
rather than silently clamping them.

No connection flush, hash-table resize, sysctl.d writes or external helper
processes. Existing durable native intents handle pre-write capture, exact
readback, rollback, restart repair and ownership removal. Restoring settings
cannot resurrect expired connections. Existing API status/authentication and
confirmation semantics are unchanged.

Release impact/recommended bump: **additive contract; next automatic calendar
version**, Unreleased. Software identity remains build/commit-derived.
**Frontend impact: required** advanced controls, scoped validation and safety
help. [Handoff 2026-11-08-01](../frontend-handoffs/2026-11-08.md#2026-11-08-01-conntrack-controls)
is **Pending frontend review**; nothing sent or acknowledged.
