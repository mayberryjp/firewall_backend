## Serialize privileged CI fixtures

### Summary and components

Fixed the test scheduling behind
[failed CI run 41923328842](https://github.com/mayberryjp/firewall_backend/actions/runs/41923328842).
Ethernet and WireGuard host-mode fixtures ran concurrently and contended for
the same host-tunables lock despite isolated networking. Standard Rust checks
passed in that run; privileged integration failed and packaging/publishing
were skipped.
