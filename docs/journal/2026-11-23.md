- Decisions/current contract:
  - `policy_sync_enabled` defaults false, requires URL, and operates independently
    of `sync_enabled`. Five-minute completion-relative polling; immediate
    enabled startup/enablement/source/relevant-host changes.
  - Conditional `GET /api/ignorelist`, complete array plus bounded opaque ETag,
    exact `If-None-Match`; `304` is no apply/revision. Verified upstream route
    and database snapshot code read-only at
    [Sando 8d0febf1](https://github.com/mayberryjp/sando/tree/8d0febf14d3921a6b92a0aa16f6032cd24adb39d).
    No upstream repository changes or live Sando tests performed.
  - Only literal unicast, same-family, exact existing source host and numeric
    TCP/UDP/ICMP/ICMPv6 entries map. TCP/UDP ports 1..65535; ICMP recorded zero
    maps without transport ports. Multiple source-family host addresses,
    wildcards, unsupported/malformed/unmatched rows and duplicate generated
    rules are skipped/countable, never widened.
  - Replace only Sando-owned host rules, retain all other rules in relative
    order, append mapped rules in source order. Preserve defaults, inventory,
    input, NAT, interface policies and one-time browser reports. Empty or
    all-skipped lists remove prior Sando-owned host rules automatically.
  - Full durable submit/apply/verify/immediate confirmation advances configuration
    revision once for effective changes. Busy/drift/failure never advances the
    validator; normal rollback and restart recovery remain active. Only
    acquisition is cancellable; an already-running blocking durable apply
    finishes before worker shutdown.
  - ETag/status are runtime-only; committed rules/history persist. Startup and
    relevant local changes invalidate the validator, avoiding missed edits.
    New `policies` is a member of the `GET /api/v1/sando` response, not an endpoint;
    existing metadata status/cache and MQTT sensors retain their meaning.
  - Delegating or disabling automatic policies, or changing their enabled URL,
    requires `firewall.write` plus existing Sando/transaction permissions.
- Contract/release impact: additive opt-in configuration/status with explicit
  firewall delegation permissions. Recommended bump: next automatic calendar
  version; compiled version/seed untouched. Effective background changes advance
  configuration revisions, not software identity.
