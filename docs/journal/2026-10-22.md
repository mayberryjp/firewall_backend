## GitHub-downloadable Ubuntu source installer

- Summary: added a standalone source bootstrap so operators do not need an
  existing checkout or Rust installation to build on Ubuntu amd64.
- Affected files: [installer](../../install.sh),
  [installation guide](../BUILD_AND_INSTALL.md), [README](../../README.md), and
  [changelog](../../CHANGELOG.md).
- Decisions/current contract: root-only Ubuntu amd64 source installation with
  APT prerequisites, stable rustup, locked GNU-target build and temporary source
  cleanup. Fetches `main` or `--ref BRANCH_TAG_OR_COMMIT` from the actual origin.
  Refuses an active daemon; no automatic service stop/start, systemd unit,
  networking changes or runtime-state deletion. Separate from signed packaging.
  Recommended bump: minor for installer functionality; baseline unassigned.
- Validation: Git Bash `bash -n install.sh`, `--help`, invalid/missing argument
  cases and non-Linux rejection passed. Scoped `git diff --check` and guide/
  journal relative-link checks passed; editor reports no installer errors.
  Ubuntu dependency provisioning,
  source fetch/build/install and active-daemon rejection were not executed on
  this Windows host. Rust tests not run: no Rust changes.
- Frontend impact: none; no API/schema/UI changes or new frontend deployment
  requirements. No new handoff; prior pending frontend items remain pending.
- Open issues/next steps: Ubuntu amd64 end-to-end acceptance remains required.
  Download URL only becomes available after an authorized commit/push containing
  the script; desired source must also be present on GitHub. No commit, push,
  release or notification performed. Service setup remains separate.
