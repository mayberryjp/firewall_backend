## Server-side Test sync preview

- Summary/why: provide one-time server retrieval/mapping that stages a candidate
  for existing frontend Save / Commit review, so operators can inspect automatic
  policy mapping without enabling unattended changes.
- Components:
  [core preview/apply](../../crates/netcontrol-core/src/engine.rs),
  [core regression](../../crates/netcontrol-core/src/engine_tests.rs),

- Decisions/current contract: bodyless
  `POST /api/v1/sando/policies/preview` requires `state.read`, `sando.write`,
  `firewall.write`, not transaction authority. Fetch committed source once
  unconditionally; return validated full candidate, base revision, source/ETag,
  counts and change indication. Reuse the automatic mapper without changing
  replacement/skip/empty behavior. No apply, revision, flag, report, worker
  status/cache/validator changes. One concurrent preview; busy/stale results
  fail explicitly. Do not hold the engine lock during fetch.
- Contract/release impact: additive endpoint; next automatic calendar version.
  Compiled software identity/immutable seed untouched. No persisted schema change.
- Frontend impact: **required**;
  [2026-11-24-01](../frontend-handoffs/2026-11-24.md#2026-11-24-01-test-sync-staged-policy-preview),
  **Pending frontend review**. Main Save / Commit frontend is outside this
  repository; embedded assets are device setup only. Stage only into a clean,
  revision-matched draft, show removals/skips, never auto-submit or enable sync.
