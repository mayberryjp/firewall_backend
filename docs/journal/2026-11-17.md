Decisions/current contract:

- Read-only Bash CLI accepts WAN and LAN interface names plus an optional
  1..60-second interval (default one). Nothing is installed, configured or

  Brief queues and changes between samples can be missed. No payload capture,
  active traffic generation, arbitrary threshold or automatic repair.
- Release impact/recommended bump: additive operator tooling; next automatic
