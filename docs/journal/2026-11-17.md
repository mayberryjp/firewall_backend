Decisions/current contract:

- Apply/verify/persist `kernel.panic=10` at native host startup only. Preserve
  trusted file checks, explicit startup failures and the kernel's own reboot
  behavior; remove the dedicated enforcement worker, runtime object and health
  row. No panic is induced. This supersedes continuous-reclamation decisions in
  the 2026-11-10 entry, not its mandatory startup/boot policy.
- Apply/verify hostname/timezone at manager startup and when their confirmed
  value changes. Retry actual failures after 30 seconds; do not reclaim later
  external drift. Status observations are cached apply/verification results,
  not continuous measurements. Explicit `system` manager restart reapplies saved
  values. Confirmation, persistence, rollback, clearing/unmanaged semantics and
  domain's display-only role remain.
- Notify managers after durable journal updates and operational pause changes.
  Disabled integrations wait for changes; active work uses actual publication,
  update, refresh and retry deadlines. Keep MQTT's five-second retries,
  configured publication/Dynamic DNS intervals, hourly Sando and enabled
  Discord's one-second drop consumption. In-flight cancellation observes events.
- Collect health separately from transaction deadlines/watchdog progress using
  nonblocking cached worker snapshots, including DHCP-backed gateway monitors,
  rather than full native runtime diagnostics. Preserve stale/unknown/error
  reporting and real failed-worker coverage.
- Replace 20 ms stop polling with a shared shutdown-signaled condition variable;
  predicate/deadline waiting prevents lost wakeups and premature timeout after
  spurious notification. Preserve worker joins, backoff, restart and final flushes.
- Release impact/recommended bump: breaking runtime/host-policy/status-observation
  contract plus efficiency/scheduling fixes; next automatic calendar version.
  No manual software version change, compatibility path or state reset.
- Frontend impact: required; [2026-11-17-01](../frontend-handoffs/2026-11-17.md#2026-11-17-01-startup-policy-and-event-driven-managers)
  is Pending frontend review. The previous panic handoff is explicitly
  superseded in part; no delivery, deployment or browser verification claimed.
