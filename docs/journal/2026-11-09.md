  [changelog](../../CHANGELOG.md) and
  [handoff 2026-11-09-04](../frontend-handoffs/2026-11-09.md#2026-11-09-04-server-side-drop-category-filtering).
  Earlier [journal decision](2026-11-08.md#frontend-only-drop-tag-filtering) and
  [handoff](../frontend-handoffs/2026-11-08.md#2026-11-08-05-frontend-only-drop-tag-filtering)
  are explicitly superseded without erasing their history.

### Decisions and contract impact

`GET /api/v1/firewall/deny-log` accepts exactly lowercase `true`/`false` query
values. Omitted/false flags exclude their categories; true includes the category
alongside other matching traffic. Overlapping records require both flags.
The TCP bucket is FIN, RST or known empty ACK-only, not all ACK packets or proof
of benign teardown. Unknown flags/payload and nonempty ACK payload are not
excluded as ACK-only.

Reuse existing `DenyLogQuery::matches` before native page limits and cursor
lookahead. Response shape, global retained boundary IDs, capture/loss metadata,
authentication (`firewall.logs.read`), strict query errors and unavailable
backend behavior remain unchanged. No new endpoint/configuration/persistence
schema, compatibility path, retention mutation, collection suppression,
notification setting change or worker concurrency change.

Release impact/recommended bump: **breaking retrieval-default change with
additive queries; next automatic calendar version**, Unreleased.
**Frontend impact: required**, server-side query controls/default messaging,
selection reset, stable flags across paging and stale-response handling.
[Item 04](../frontend-handoffs/2026-11-09.md#2026-11-09-04-server-side-drop-category-filtering)
is **Pending frontend review**, not sent or acknowledged.
